# Teardown: learn from a viral piece without imitating it

Copying a viral article's sentences, rhythm or tone usually produces something that is only similar on the surface. What transfers is the mechanism: why the piece keeps people reading.

## Contents
- Questions to ask of the piece
- Output
- Rules

## Questions to ask of the piece

1. **Why keep reading?** Does it open with a specific predicament the reader recognizes?
2. **How fast does it commit?** How soon does it give a clear judgment, and what is it?
3. **What carries it forward?** Scenes, contrasts, evidence, a question that gets answered later? What does each paragraph add?
4. **Where does the emotional need get met?** Which passage makes the reader feel understood, reminded, encouraged or more certain?
5. **How does it end?** Does it hand the reader a next step or a natural continuation, or does it just summarize?
6. **What would break if you removed the author?** Which parts depend on this particular person's experience, and so cannot be borrowed?

## Output

```markdown
# Teardown: <piece title or link>

**One-line reason it works:** …

## Mechanisms
| Mechanism | How it shows up | Can I borrow it? |
|---|---|---|
| Opening | e.g. starts from a named predicament in the first two lines | yes |
| Judgment timing | … | |
| Engine | … | |
| Emotional payoff | … | |
| Ending | … | |

## Depends on the original author (don't copy)
- …

## Mechanisms to try in my own piece
1. <a mechanism, written as an instruction>
2. …
```

The last list can be added to the author's `voice-profile.md` as preferred structure.

## Rules
- Don't reproduce the article's text beyond a few words for evidence. Describe, don't quote at length.
- Separate the mechanism (borrowable) from the author's personal material (not borrowable).
- Don't suggest copying sentence patterns. Suggest the underlying move, and let the author express it in their own words.
